# Studio App Icon Source

`app-icon-source.png` is a 1024 by 1024 crop of
`macos/presets/preset-midnight-aurora/background.jpg`. The preset is procedural
art generated by `macos/presets/generate-presets.mjs` and distributed under the
repository's MIT license.

The tracked source was created without additional artwork using:

```sh
sips -c 1024 1024 macos/presets/preset-midnight-aurora/background.jpg --out studio/assets/app-icon-source.png
```

Because `sips` preserves the input encoding for that exact crop command, the
same path is then atomically normalized to PNG with `sips -s format png`. No
second source asset is retained.
